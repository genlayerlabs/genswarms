Это как операционная система.

Операционная система выполняет чужие программы. GenSwarms делает то же самое для агентов: запускает их, изолирует, маршрутизирует их сообщения и перезапускает после сбоя.

Каждый агент — это процесс.

У каждого своя песочница и свой супервизор. Упавший агент перезапускается, а остальные продолжают работать. Роль агента, его модель и место запуска вы задаёте по отдельности.

Агенты общаются только по объявленным маршрутам.

Граф задаёте вы. Каждое сообщение сверяется с ним, а всё, что вне графа, отбрасывается.

Как это работает.

Части операционной системы и то, что GenSwarms предлагает для каждой из них.

Процессы
Каждый агент — OTP-процесс под супервизором: роль, модель и бэкенд задаются отдельно.
Изоляция
bwrap, Docker или Apple container для каждого агента.
Сеть
Изолированным агентам доступен только эндпоинт их модели.
Сообщения
Только по объявленным маршрутам, с проверкой на каждом шаге.
Сервисы
Объекты: детерминированный код на том же графе.
Драйверы
Local, Tmux, Docker, Apple container, SSH, Bwrap, Mock.
Пакеты
gsp и swarmidx: подписаны, адресуются по содержимому, проверяются на вашей машине.
Состояние
Исходное состояние плюс журнал изменений. Недопустимые изменения отклоняются. Восстановление из базы данных.
Управление
REST, WebSocket, CLI и файл навыка для вашего кодинг-агента.
События
Каждое сообщение, сбой и перезапуск — в реальном времени.

Чем это отличается от LangGraph, CrewAI или AutoGen?

Фреймворки организуют агентов внутри вашего кода. GenSwarms запускает каждого агента как отдельный процесс под супервизором.

Что гарантировано, а что — пока нет.

Что входит в версию 0.2.0 сегодня и о каких ограничениях мы знаем.

Гарантии

  • При сбое перезапускается один агент, а не весь рой.
  • Сообщения идут только по объявленным маршрутам.
  • Недопустимые конфигурации и изменения отклоняются до запуска.
  • Пакеты проверяются по подписанному журналу.

Пока нет

  • Один токен оператора, без ролей для отдельных пользователей.
  • Доставка «как минимум один раз», а не «ровно один раз».
  • Бюджеты расходов — в отдельном пакете, а не в ядре.
  • Обновление пакета перезапускает агента; горячей замены пока нет.
  • По умолчанию 100 агентов на рой (настраивается).

Сначала — одна команда. Дальше — тысячи агентов.

Уже применяется для чат-ассистентов, кодинг-агентов, торговых симуляций и роёв, которые следят за другими роями.
